# VOLTERRA — Meridian-inspired editorial concept

A complete runnable Next.js front-end concept with a dark, warm editorial visual direction inspired by the **interaction and composition language** of the supplied reference, not copied branding, text, or assets.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Routes

- `/` Home
- `/vehicles` Vehicle index
- `/vehicles/volterra-x1`, `/vehicles/volterra-s`, `/vehicles/volterra-moto`, `/vehicles/volterra-city`
- `/compare` Interactive comparison
- `/calculator` Interactive illustrative cost calculator
- `/charging` Demo charging discovery
- `/insights` and article routes
- `/contact` Validated front-end demonstration form

## Note

This ZIP is a polished working **front-end foundation**. It does not pretend to provide a database, real admin, email delivery, live maps, or production authentication. Those require environment secrets, a deployed database and a server-side integration. All vehicles, locations and figures are clearly fictional demo content.
